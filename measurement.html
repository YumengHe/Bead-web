拼豆熨烫标定测量

搭建 simulation 之前，需要先用实物测出熨烫会让豆子发生哪些变化、变化多大。这一页列出要测的数据、测试板怎么摆、怎么记录，以及测完以后怎么判断下一步。

单位：mm · s一个品牌 · 一个熨斗档位只变熨烫时间

English summary: Before building the simulation, we iron small calibration boards at several durations and measure bead size, hole closure, bonding, shrinkage, warping and color change. These numbers calibrate Stage 2 (material-aware adjustment) and Stage 3 (ironed-result prediction), and decide whether simple adjacency rules are enough.

Stage 0 是什么 What Stage 0 Is

Stage 0 是写任何代码之前做的实物标定实验：把设计好的小图案摆在拼豆板上，用不同时间熨烫，测量熨烫前后的变化。它不属于 pipeline 本身，而是给 pipeline 提供数据。现有的工具和熨烫指南只定性地说"会缩小、孔会闭合、会翘曲"，没有任何数值。

Stage 0实物标定：测出熨烫带来的变化
参数 →
Stage 1 · Layout按大小和颜色生成拼豆布局
Stage 2 · 材质调整处理晕染和断连
Stage 3 · 熨后预测预测熨烫后的样子，可反推调整 layout
后面的 stage需要 Stage 0 提供什么没有这些数据会怎样
Stage 1每种豆子熨烫后的真实颜色配色只能用色卡标称值，成品颜色可能和预期不一样
Stage 2哪些连接一定粘上、哪些会断，晕染有多宽连通性规则只能凭感觉写，比如不知道对角相邻算不算连通
Stage 3膨胀多少、孔闭合多少、整体缩多少熔合模型没有参数，"熨后效果"没有依据

Stage 0 还要回答一个决定项目方向的问题：熨烫后的结果能不能用简单规则解释？能的话，Stage 2 用图论规则、Stage 3 用查表就够了；不能的话，就需要标定一个真正的熔合模型，这也是项目最有 novelty 的地方。判断标准见页面下方的 Go / No-Go。

Stage 0 runs before any code. It supplies the parameters for Stages 1–3 and decides whether simple adjacency rules are enough or a calibrated fusion model is needed.

三个核心问题 Core Questions

Q1 · 尺寸

一颗豆子熨烫前后各多少 mm？

外径、孔径、高度，在每个熨烫时间下各测一次。

Q2 · 粘合

两颗豆子熨多久会粘在一起？

边相邻、对角相邻、隔一格，分别在 5 s、10 s、15 s… 记录粘上没有。

Q3 · 闭孔

豆子多久变成无孔豆？

孤立的豆子和被 2、3、4 颗豆包围的豆子，闭孔时间可能不同。

测试板布局 Calibration Board

所有测试图案摆在同一块 29×29 方形板上，图案之间至少空 2 格，避免互相粘连。每个时间档熨一整块板。

  • P1单颗孤立豆：没有邻居时的膨胀和闭孔
  • P2两颗边相邻：最基本的粘合
  • P3两颗对角相邻：膨胀后对角能不能粘上
  • P41 格宽直线，长 10、5、3：细颈强度
  • P52 格宽直线，长 10：和 P4 对比加宽的效果
  • P65×5 实心块：角、边、中心的邻居数差异，整体收缩
  • P7X 形，只有对角接触：全靠对角的结构能否提起
  • P8双色交界（黑/白、红/白）：晕染
  • P9色卡条，每色 3 颗：颜色变化
  • P10隔一格的两颗豆：膨胀能否跨过空格

图中颜色只是示意，实际用你们买到的颜色。P8 和 P9 需要真实颜色，其余图案可以用同一种颜色，方便量尺寸。

实验设置 Protocol

固定不变

  • 豆子品牌和尺寸（只用一个品牌）
  • 熨斗档位；有红外测温枪的话记录底板实际温度
  • 熨烫纸、垫板
  • 手法：只靠熨斗自重，轻轻画圈
  • 完全冷却后再测量
  • 先只熨单面

唯一变量：熨烫时间

计时 = 熨斗在整块板上画圈移动的总时间。

5 s10 s15 s20 s30 s

这组数值是初始猜测。先做一块预实验板，找到"刚开始粘"和"孔完全闭合"的大致时间，再在这个范围内平均取 5 档。

数量

  • 5 个时间档 × 每档 3 块 = 15 块板
  • 熨烫不可逆，每档必须用新板，不能在同一块板上分段继续熨
  • 第二轮（可选）：双面熨烫、换一个品牌

测完以后怎么判断 Go / No-Go

简单规则就够

  • 边相邻过了某个时间就一定粘上
  • 对角永远粘不上，隔一格也粘不上
  • 闭孔时间和邻居数基本无关
  • 细颈只要边相邻就能拿起，跟长度无关

这时 Stage 2 用连通性规则就能做，Stage 3 可以简化成查表。

需要标定的熔合模型

  • 对角在某个时间之后开始粘上
  • 闭孔明显依赖邻居数
  • 同样是边相邻，细颈长了就会断
  • 晕染宽度随时间明显变化

这些都是"图结构相同、物理结果不同"的情况（Legolization 的论点），说明需要完整的 Stage 2 和 Stage 3。

If bonding, hole closure or neck strength depend on time, neighbor count or length beyond a simple adjacency rule, a calibrated fusion model is justified.

器材 Equipment

必需

  • 一个品牌的豆子：黑、白、红，再加 3 种常用色
  • 2–3 块 29×29 方形板（可重复使用）
  • 熨斗、熨烫纸
  • 游标卡尺、钢尺、计时器
  • 平板扫描仪（600 dpi），或手机加三脚架俯拍

可选

  • 红外测温枪：记录熨斗底板实际温度
  • 扫描一张熨烫纸的纹理，给 Stage 3 的渲染器叠加用
