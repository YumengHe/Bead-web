Pipeline   
There should be a three-stage pipeline with a preparation stage that defines the standard work as the baseline. 

For preparation, we should understand all kinds of changes that different ironing processes may make and consider them as the standard, then build a simple fusion model.   
For color, we first test how a single different color may change after ironing, then test how multi-color changes and how the blending process may differ because of the different arrangement of neighbors. All these results are compared with color alta.  
For the structure of the beads, we can use homography with the pixel web and then test how ironing time, pressure, temperature, and different neighbors may change the final output. For simplification, we can use the same color, white or black.  
For the physical status test, based on the former output we gain from the structure test, we can try to hang the weight to see each structure’s connection strength. (We can try to test with different positions of the output to generalize the break point.)  
We use all the data we gain from the former test to build a simple fusion model.

For stage 1, we want to output the pixel layout. The possible inputs should be text or image, as well as the selected board and color set. The current model already has the ability to do this process (with a limited color set, remove the background, change color or erase the color if needed, change the board size), but for image input, there are two situations that we need to consider and make some improvements. First, when the input image is larger than the board, we need to downscale the image, and if the opposite situation, we enlarge the image and reinforce it if indeed.  
We can start the optimization from parts; we first divide the image into parts. We can also consider the whole unit as many connected triangles, and this will help us to analyze the physical structure.  
Here we should emphasize that the color and the arrangement should be optimized together for better layout output.

For Stage 2, we want to do some structural analysis of the layout and reduce the unnecessary beads to optimize the bead count while keeping the structure connected and physically stable.   
For reducing the beads, we consider two parts: visual optimization and physical structure optimization. We will try to find the important beads(superpixels) or the sketch of the layout and keep them. Then we try to analyze the structure first to find the important bead parts that keep the output connected(cut points). Also, for physical purposes, we try to analyze the most likely break line in different situations (hang, handle). Those are the beads we need to keep; then we can try to reduce some less important beads and optimize it by rearranging them at the same time as a loop. We can define the final optimized times to avoid an infinite loop. Similarly, we start from small parts to the whole, and we will need the defined limit for reduced beads or add beads for physical stability.   
For stage 3, we may consider two directions: the forward direction and the reverse direction.  
For the forward direction, we have the optimized layout pixel image input from stage 2, and we want to simulate the image of the layout after the ironing process. The process we did during the preparation stage worked. We will consider the blending influence and, based on the fusion model, predict the possible output for certain ironing situations. We need to compare the simulation output with the real final output and to see the loss using the defined loss function with some important variables(like color and structure). Then try to optimize it through adjustments.   
For the reverse direction, we will have a real layout after the ironing process, and we want to simulate the matching pixel layout before ironing. We also base it on the preparation stage but in a reverse way and optimize it to have less loss.
